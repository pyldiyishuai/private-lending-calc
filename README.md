## 一、两条规则决定你能少还多少

### 规则一：砍头息不算本金

《民法典》第 670 条：**借款的利息不得预先在本金中扣除。**

借 10 万、先扣 5 千，法律上的本金就是 **9.5 万**，不是 10 万。

不只是本金少了 5 千——所有利息都按 9.5 万重算，真实利率也被拉高了一截。

### 规则二：利率上限 = 合同成立时的一年期 LPR × 4

关键词是**「合同成立时」**，不是起诉时、不是还款时。

```
2023-01-01 签的合同 → 当天 LPR 3.65% → 上限 14.60%
2025-06-01 签的合同 → 当天 LPR 3.00% → 上限 12.00%
```

约定 24% 的，超出 14.60% 的那部分**不受法律保护**。

### 2020 年 8 月 20 日是新旧分界

| 合同成立时间 | 适用规则 | 上限 |
|---|---|---|
| 2020-08-20 之后 | 四倍 LPR | 约 12%–17% |
| 2020-08-20 之前 | 两线三区 | 24% / 36% |

旧规的「两线三区」：
- ≤24% 完全保护
- 24%–36% 自然债务区（已付不退、未付不支持）
- >36% 无效，已付可要求返还

## 二、算例（工具默认值）

借 10 万，砍头息 5 千，约定年利率 24%，借一年（2023-01-01 → 2024-01-01），已还 3 万。

| 项目 | 金额 |
|---|---|
| 账面本金 | ¥100,000 |
| 砍头息 | −¥5,000 |
| **实际本金** | **¥95,000** |
| 借款日 LPR | 3.65% |
| 四倍上限 | 14.60% |
| 约定利息 | ¥22,800 |
| **合法利息** | **¥13,870** |
| 不受保护的利息 | ¥8,930 |
| 按法定上限应还 | ¥108,870 |
| 已还 | −¥30,000 |
| **还需还** | **¥78,870** |

按约定利率算要还 ¥117,800。**省下 ¥8,930。**

## 五、改代码前必看

### 1. 合法利息要取 min(约定利率, 上限)

```js
var legalInterest = principal * Math.min(rate, cap) * years;   // ✅
var legalInterest = principal * cap * years;                    // ❌
```

约定 12%、上限 14.6% 时，合法利息应该是 12% 算出来的，
不该按 14.6% 算。写错会让「不超标」的用户凭空多出利息。

### 2. LPR 要按「合同成立时」查

不是 `new Date()` 的 LPR。用户 2023 年借的钱，
要用 2023 年那天的 LPR，不是今天的。

### 3. 复利的年数要用实际天数 / 365

三年含一个闰年是 1096 天 = 3.0027 年，不是 3 年。
差一点点，但复利会放大。

### 4. 砍头息扣完之后本金可能 ≤ 0

极端输入（砍头息 > 本金）要有兜底，否则后面全除以 0。

## 八、免责

本工具依据《民法典》第六百七十条、第六百八十条，以及最高人民法院
《关于审理民间借贷案件适用法律若干问题的规定》（2020 年修正）计算。

四倍上限取合同成立时的一年期 LPR；2020 年 8 月 20 日之前的合同
适用 24%/36% 旧规。本工具按单利计算（可选复利），
未考虑违约金、罚息的具体约定形式，结果仅供参考，不构成法律意见。
